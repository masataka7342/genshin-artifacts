# 原神 聖遺物 原神Wiki推奨ビルド AI診断 & オプティマイザー

日本の最大級原神攻略サイト **原神Wiki (https://wikiwiki.jp/genshinwiki/)** のキャラクター育成・聖遺物ビルド解説データを参照し、聖遺物やインベントリのスクリーンショットをAI（Gemini 2.5 Flash）で自動解析して、**「所持している聖遺物の中からそのキャラに何を装備すればいいのか（最強の5部位）」を自動選定**するWebアプリケーションです。

---

## 🌟 主な機能

### 1. 🏆 5部位ベスト装備 自動選定 (Artifact Optimizer)
- 手持ちの聖遺物プールの中から、選択したキャラ（シロネン、フリーナ、マーヴィカ、ヌヴィレット、アルレッキーノなど）に最も合う**「生の花」「死の羽」「時の砂」「空の杯」「理の冠」の最強組み合わせ**を自動計算して提示！
- **原神Wiki推奨4セット効果の発動**（灰燼の都に立ち栄える勇者4、黒曜の秘典4、黄金の劇団4、ファントムハンター4、絶縁4など）と、最もステータスが高いオフピース枠を賢く判定。
- 装備セット全体の**合計CV（会心スコア）**と**合計有効ロール数（RV）**を瞬時に算出。

### 2. 🎒 インベントリ / 複数スクショの一括解析
- ゲーム内のインベントリ画面（バッグ画面）や聖遺物詳細画面のスクショを**複数枚まとめてドラッグ＆ドロップ**可能！
- `Ctrl + V` によるクリップボード直接貼り付けにも対応。
- アップロードされた聖遺物は自動的に「所持聖遺物プール」へ蓄積され、オプティマイザーの計算対象になります。

### 3. 📚 原神Wiki (wikiwiki.jp) ビルドデータ完全準拠
- 各キャラクターの解説カードから、**原神Wikiの個別キャラクターページへ直接ワンクリックでリンク**。
- 日本語公式用語に完全対応（時の砂、空の杯、理の冠、各元素ダメージバフ等）。
- ナタ環境を含む現環境の主要キャラクター（30名以上）のビルド指針を網羅。

## 🚀 起動方法

### 最も簡単な方法（ブラウザで直接開く）
`d:\AG\index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップしてください。
（Node.js や Python などの追加インストールは不要です）

### PowerShell から起動する場合:
```powershell
Start-Process "d:\AG\index.html"
```

---

## 🔑 Gemini API キーの設定（画像解析用）
1. 画面右上の入力欄に Google AI Studio で発行した **Gemini API Key** を入力して「保存」をクリックします。
2. APIキーはブラウザの `localStorage` にのみ安全に保存されます。
3. ※ APIキーがない場合でも、最初から内蔵されている手持ち聖遺物プリセットで、全オプティマイザー機能をお試しいただけます。
